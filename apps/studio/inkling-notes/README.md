# Inkling Mobile

Inkling mobile is a Studio candidate, not yet an implementation.

## Mobile Job

Capture notes, images, voice, and links into a local-first vault with offline
enrichment.

## Native Bias

- Use native camera, OCR, and speech capture.
- Use platform AI for local cleanup, summarization, and extraction.
- Use Rust for vault semantics, markdown transforms, embeddings, vector search,
  sync contracts, and replayable import logic.
