# Wolfgang Mobile

Wolfgang mobile is a Studio candidate, not yet an implementation.

## Mobile Job

Give the user a portable research companion for capturing material, asking
grounded questions, and continuing a thread away from the desktop app.

## Native Bias

- Use native speech and camera/OCR for capture.
- Use platform GenAI when local rewriting, extraction, or summaries are enough.
- Use Rust for persona policy, memory contracts, citations, embeddings, and
  sync with the desktop/web Wolfgang core.
