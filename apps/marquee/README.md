# Marquee Mobile Apps

Marquee mobile apps should be thin, field-ready product surfaces over the
existing Marquee portfolio. They should emphasize capture, consent, live
coordination, offline operation, and proof artifacts rather than broad desktop
workbench behavior.

## Initial Priority

1. `quorum-sense` - mobile live inquiry, signal capture, and participant-facing
   sensemaking.

Other Marquee apps can be added when their mobile job is specific enough to
justify native shells.
