# Quorum Android

Kotlin/Compose shell placeholder for Quorum Mobile.

Create the real Android project here when the first workflow is specified:

1. Capture a signal from text, voice, or photo.
2. Use native Android frameworks for transcription, extraction, and media
   capture.
3. Send the consented structured draft through the UniFFI bridge into Rust.
4. Replay the same fixture through Rust tests before wiring cloud sync.

Expected native packages:

```text
app/
capture/
platformai/
corebridge/
```
