# Quorum Mobile

Quorum is the first Marquee mobile candidate.

## Mobile Job

Help an organization capture live signal, preserve ambiguity, and move toward
quorum while people are away from a desktop.

## Expected Native Work

iOS:

- SwiftUI participant and facilitator flows
- Foundation Models for local summarization, extraction, and structured signal
  drafts
- Speech for live transcription
- Vision and AVFoundation for photo/camera signal capture
- App Intents for quick capture

Android:

- Compose participant and facilitator flows
- Gemini Nano and ML Kit GenAI APIs for local summaries and extraction
- CameraX for capture
- ML Kit for OCR and document/signal extraction
- MediaPipe where realtime visual signals become product-critical

Rust:

- Inquiry thread state
- Signal and hypothesis DTOs
- fuzzy confidence handling
- offline event queue
- replay and deterministic checks
- vector memory contracts
- AI routing policy

## First Workflow To Specify

Capture a field signal from text, voice, or photo, create a local structured
draft, let the user consent, then append it to a Quorum inquiry thread when
online.
